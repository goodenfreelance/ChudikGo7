## 1. Обзор проекта

**«Сетка Чудиков»** — это многопользовательская физическая 2D-песочница с моделированием сочленённых биомеханических существ (чудиков), живущих на тороидальной координатной сетке.

Игроки могут:
- Конструировать уникальных чудиков в интерактивном векторном редакторе (выбирать расположение головы, рёбер каркаса, шарниров сочленений и мышечных волокон).
- Запускать своих существ в общий мир соревноваться за ресурсы (еду), расти в массе, размножаться и взаимодействовать по законам физики Ньютона.
- Управлять своим чудиком в реальном времени (повороты, рулежка, рывок/Dash с расходом энергии) или наблюдать за автономными алгоритмами поведения ботов.
- Общаться в чате, соревноваться за верхние строчки в динамическом лидерборде и просматривать системные логи работы физического движка.

## 2. Архитектура системы

Проект построен по высокопроизводительной гибридной архитектуре:

```
┌─────────────────────────────────────────────────────────────┐
│                    Браузер (Клиент)                         │
│  - React 18 + TypeScript + Vite                             │
│  - HTML5 Canvas (60 FPS интерполяция + Камера + Зум)        │
│  - Векторный SVG Конструктор + Стилизация Tailwind CSS     │
└──────────────────────────────┬──────────────────────────────┘
                               │  HTTP REST & WebSocket (Порт 3000)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│               Node.js / Express Gateway (Порт 3000)         │
│  - Reverse Proxy для WebSockets                             │
│  - SQLite База данных (Пользователи, Хеширование bcrypt)    │
│  - Аутентификация JWT / Сессии                              │
│  - REST API (/api/health, /api/auth, /api/logs)             │
│  - Статический хостинг фронтенда (dist)                     │
└──────────────────────────────┬──────────────────────────────┘
                               │  IPC / TCP Proxy (Порт 8089)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│               Go Backend Engine (Порт 8089)                 │
│  - Высокоскоростной тик-сервер (до 100 тиков/сек)           │
│  - Пространственная сетка Spatial Partitioning Grid         │
│  - Физика сочленённых тел (Rigid-body & Joint Dynamics)     │
│  - Ударные импульсы, сохранение момента, Anti-Overlap       │
│  - Интеллект ботов (Поиск еды, маневрирование)              │
│  - Комната многопользовательской синхронизации              │
└─────────────────────────────────────────────────────────────┘
```

### Основные компоненты:
1. **Клиент (`/src`)**:
   - `GridCanvas.tsx`: Главный холст отрисовки мира со сглаженной интерполяцией между тиками сервера, динамическим зумом, миникартой и следованием камеры.
   - `CreatureEditor.tsx`: Интерактивный редактор чудика с авто-расчетом массы, момента инерции, силы тяги, проверкой связности графа и визуализацией векторов тяги.
   - `websocket.ts`: Клиентский менеджер протокола WebSocket с авто-переподключением и оффлайн-фоллбэком физики.
2. **Шлюз Node.js (`server.ts`)**:
   - Маршрутизация внешнего трафика на единый порт 3000.
   - База данных SQLite (`src/db/users-db.ts`) с безопасным хранением учетных записей (пользователь `joni` / `PinokiO`).
   - Менеджер жизненного цикла бинарного процесса Go-сервера.
3. **Физический сервер Go (`server-go/`)**:
   - `game/physics.go`: Математическое ядро физики, расчет кинематики мышц, детекция столкновений и упругие импульсы.
   - `game/room.go`: Игровой мир, жизненный цикл существ, спавн еды, мутации и размножение.
   - `game/spatial.go`: Пространственная сетка для ускорения поиска коллизий $O(N \log N)$.
   - `ws/hub.go` и `ws/client.go`: Обработка подключений и широковещательная рассылка обновлений состояния.

## 3. Биомеханика и Конструктор Чудиков

Чудик строится на локальной координатной сетке (от $5 \times 5$ до $15 \times 15$). Каждое существо состоит из дискретных анатомических элементов:

| Элемент | Визуальное обозначение | Масса ($m$) | Назначение |
| :--- | :--- | :--- | :--- |
| **Голова (Head)** | 🟡 Золотой круг с глазами | $1.0$ | Центр ориентации, точка приёма пищи и направление взгляда. |
| **Ребро (Bone / Carcass)** | ⚪ Серая линия/сегмент | $1.0$ | Силовой каркас чудика, соединяющий шарниры. |
| **Шарнир (Joint)** | 🔵 Голубая точка сочленения | $0.0$ | Ось вращения, делящая чудика на левое и правое плечо. |
| **Мышца (Muscle)** | 🔴 Красная дуга/тяга | $0.0$ | Активно сжимается и разжимается каждый шаг, создавая момент силы. |
| **Случайная Мышца (🎲)** | 🟣 Фиолетовая дуга | $0.0$ | Срабатывает стохастически с вероятностью $P \in [4\%, 20\%]$. |
| **Глаз (Eye)** | 👁️ Сенсор | $0.2$ | Увеличивает радиус обнаружения еды и угрозы. |
| **Рот (Mouth)** | 👄 Жевательный аппарат | $0.5$ | Увеличивает эффективность поглощения еды. |

### Проверка Связности Конструкции (Graph Connectivity)
В редакторе встроен алгоритм поиска в ширину (BFS). Если игрок ставит деталь в воздухе, не соединённую с головой и каркасом, интерфейс выводит предупреждение **«Ошибка конструкции: Оторванные элементы»** и блокирует сохранение невалидного существа.

## 4. Физический Движок и Математическая модель

### 4.1. Расчет Массы и Момента Инерции
- **Общая масса ($M$)**:
  $$M = \sum_{i=1}^{N} m_i$$
- **Момент инерции ($I$)**:
  $$I = \sum_{i=1}^{N} m_i \cdot r_i^2 \approx M \cdot R_{bounds}^2 \cdot 0.5$$

### 4.2. Правило Легкого Плеча и Создание Тяги
Каждая мышца действует на соединенное с ней ребро относительно ближайшего шарнира:
1. Шарнир делит тело чудика на **Левое плечо** ($m_{left}$) и **Правое плечо** ($m_{right}$).
2. **Правило легкого плеча:** Поворачивается то плечо, масса которого строго меньше ($m_{light} < m_{heavy}$). При равенстве плеч выбор направления равновероятен.
3. Разность вращательных моментов ($\Delta \tau = \tau_{left} - \tau_{right}$) приводит к повороту курса на угол $\Delta \theta = \frac{\Delta \tau}{M}$.
4. Симметричная составляющая усилий ($\min(\tau_{left}, \tau_{right})$) трансформируется в **поступательный импульс скорости вперед ($v_{forward}$)**:
   $$v_x = v_{forward} \cdot \cos(\theta), \quad v_y = v_{forward} \cdot \sin(\theta)$$

### 4.3. Коллизии и Закон Сохранения Импульса
Столкновения чудиков между собой и препятствиями моделируются в 2 фазы:
1. **Broad-phase:** Ограничивающие сферы радиусов $R_A + R_B$.
2. **Narrow-phase:** Поэлементная проверка расстояний между сегментами $d_{min} < D_{touch} = 1.0$ кл.

При соприкосновении тел рассчитывается нормаль $\vec{n} = \frac{p_B - p_A}{\|p_B - p_A\|}$ и упругий ударный импульс:
$$J = \frac{(1 + e) \cdot v_{rel}}{\frac{1}{m_A} + \frac{1}{m_B}}$$
где $e = 0.5$ — коэффициент восстановления при ударе.

Для предотвращения взаимопроникновения (Anti-Overlap) применяется позиционный сдвиг без паразитного закручивания:
$$\Delta \vec{x}_A = -\vec{n} \cdot \delta \cdot \frac{m_B}{m_A + m_B}, \quad \Delta \vec{x}_B = +\vec{n} \cdot \delta \cdot \frac{m_A}{m_A + m_B}$$

## 5. Игровые механики и Симуляция

1. **Тороидальный Мир:**
   Поле замкнуто само на себя по осям X и Y. При выходе за границу $X > R$ существо плавно появляется с противоположной стороны $X = -R$.
2. **Питание и Рост:**
   На карте генерируется питательная пыльца/еда. Касание ртом или головой добавляет чудику энергию и массу. При накоплении порога энергии чудик может размножиться с вероятностью мутации цвета или строения.
3. **Рывок (Dash):**
   Игрок может активировать форсаж (Клавиша **Space**). Скорость увеличивается на $+60\%$, при этом расходуется запас накопленной энергии.
4. **Автономные Боты:**
   Боты используют пространственный радар для сканирования ближайших источников пищи и уклонения от массивных соперников.

## 6. Сетевой стек и Протокол WebSocket

Обмен сообщениями между клиентом и сервером происходит в бинарном JSON-формате по WebSocket:

### Основные типы пакетов:
- `init` (C $\rightarrow$ S): Первичная инициализация игрока, имя, цвет и базовая конфигурация.
- `state_sync` (S $\rightarrow$ C): Высокочастотный снимок мира (координаты чудиков, углы, фазы сокращения мышц, еда, лидерборд).
- `spawn_creature` (C $\rightarrow$ S): Отправка сконструированного чудика из редактора на игровое поле.
- `steer` (C $\rightarrow$ S): Рулевое управление направлением чудика (`angleDeg`, `dash: boolean`).
- `chat_message` (C $\leftrightarrow$ S): Текстовые сообщения многопользовательского чата.
- `admin_set_speed` (C $\rightarrow$ S): Изменение скорости симуляции и постановка на паузу.

## 7. База данных и Аутентификация

- **СУБД:** SQLite (`better-sqlite3`), локальное хранение в файле `creatures.db`.
- **Безопасность:** Пароли пользователей хешируются с солью через `bcryptjs`.
- **Предустановленный администратор:**
  - **Логин:** `joni`
  - **Пароль:** `PinokiO`
- **Функционал учетных записей:**
  - Сохранение чертежей чудиков в личную библиотеку (включая количество деталей и пресеты).
  - Персональная статистика (максимальная масса, победы, время жизни).
  - Панель администратора с управлением параметрами мира (гравитация, скорость спавна еды, очистка карты, просмотр системных логов).

## 9. Инструкция по установке, сборке и запуску

### Предварительные требования:
- **Node.js**: версия 18 или новее
- **Go**: версия 1.20 или новее (для компиляции физического ядра)

### Установка зависимостей:
```bash
npm install
```

### Сборка сервера Go:
```bash
bash ./scripts/ensure-go.sh
```
*(Скрипт скомпилирует `server-go/main.go` в бинарный файл `dist/go-server`)*

### Запуск в режиме разработки:
```bash
npm run dev
```
Сервер автоматически запустит Node.js на порту `3000`, скомпилирует и подключит фоновый Go-движок на порту `8089`, а также предоставит доступ к веб-интерфейсу.

### Сборка для Production:
```bash
npm run build
npm start
```
Команда выполнит сборку клиентской части Vite в каталог `dist/`, скомпилирует `server.ts` в оптимизированный бандл `dist/server.cjs` и запустит единый production-сервер.
